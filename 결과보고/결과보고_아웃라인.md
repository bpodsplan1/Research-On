## 1. Executive Summary (한 장 요약)

발표 맨 앞에 배치, 나머지 슬라이드는 이 한 장의 부연 설명이 되도록 구성

- **한 일**: 흩어져 있던 시장·업무 관련 뉴스 리서치를 AI가 수집·분석·요약해주는 **웹 기반 도구**를 만들었다
- **핵심 결과물 2가지**
  1. **주간 뉴스레터 자동 발송** — 매주 월요일, 클라이언트·업무·인사이트·트렌드 4개 주제로 자동 작성되어 메일로 발송
  2. **리서치 허브(웹사이트)** — 임직원이 원하는 키워드를 검색하면 AI가 관련 기사를 찾아주고, 원하는 자료를 골라 심층 분석 리포트까지 만들어줌
- **기간**: 2026.04.22 ~ 07.28 (당초 8주 → 안정적 완성을 위해 14주로 조정)
- **한 줄 기대효과**: 리서치에 들이던 시간을 줄이고, 보직자 판단에 필요한 정보를 매주 정리된 형태로 자동 제공

## 2. 추진 배경

- 시장·사업 관련 정보 탐색과 활용 필요성 증대 → 그러나 개인별 수작업 리서치는 시간 소모가 크고 품질도 편차가 큼
- "정보를 찾는 것"이 아니라 "정리된 정보를 받아보는 것"으로 전환할 필요
- → T/F를 구성해 **키워드 기반 정보 수집·분석·제공 체계**를 설계하고, 웹앱 형태로 구현

## 4. 시스템 구성 (전체 그림)

한 장짜리 구성도 필수 — 비개발자도 "화살표 3~4개"로 흐름을 이해할 수 있게

```
[임직원]
   │ 키워드 검색 / 메일 수신
   ▼
[Research On 웹사이트] ──▶ [AI 자동화 엔진] ──▶ [뉴스·정보 수집]
   │                              │
   ▼                              ▼
[저장 자료함 · 검색 히스토리]   [주간 뉴스레터 자동 발송]
```

- 웹사이트: 임직원이 직접 쓰는 화면 (PC/모바일 대응)
- AI 자동화 엔진: 정보 수집 → 관련성 판단 → 요약까지 사람 개입 없이 처리(뉴스레터는 발송 전 담당자 최종 검토)
- 데이터 저장소: 검색·발송 이력을 안전하게 누적 관리(보안 조치 완료, 6번 항목에서 별도 설명)

## 5. 핵심 기능 소개 (스크린샷 위주, 3개 파트로 분리)

### 5-1. 주간 뉴스레터 — "매주 정리된 정보를 받아본다"

- 4개 섹션 자동 구성: **클라이언트 동향 / 리서치 인사이트 / 업무 관련 뉴스 / 트렌드(피플&컬처)**
- AI가 기사를 고르고 시사점까지 작성 → 담당자가 화면에서 바로 검토·수정 후 발송(사람이 최종 확인하는 구조 → 신뢰도 확보)
- 매주 월요일 오전 자동 발송, 구독 신청/해지 자율 관리

### 5-2. 리서치 허브 — "궁금한 키워드를 검색하면 AI가 찾아준다"

- 핵심 키워드 68개(업무 연관) + 확장 키워드 체계로 검색 폭 확보
- 검색 → 관련 기사 자동 선별 → 마음에 드는 자료를 고르면 AI가 **Executive Brief·분석·추천 액션**까지 담은 심층 리포트 생성
- 만들어진 자료는 자료함에 누적 저장, 언제든 재조회 가능

### 5-3. 관리 체계 — "안심하고 쓸 수 있는 운영 기반"

- 계정/권한 관리, 문의·오류 신고 접수 및 답변 처리
- 사내 이메일(@etners.com) 기준 접근 제한
- 보안 점검 통해 데이터 접근 권한 전면 재정비 완료 *(전문용어 없이: "외부 접근 위험 요소를 점검해 조치했다" 정도로만 언급)*

## 7. 기대 효과

Before / After 대비로 임원이 체감할 수 있게

- **Before**: 개인별 수작업 검색 → 시간 소모, 품질 편차, 정보 공유 안 됨
- **After**: 키워드 기반 자동 수집 + 주간 정기 브리핑 → 리서치 시간 절감, 보직자 의사결정에 필요한 정보를 표준화된 형태로 상시 제공
- 확장 가능성: 다른 사업부 키워드로 확장 시 동일 구조 재사용 가능 → 조직 전체 정보 공유 인프라로 발전 여지
